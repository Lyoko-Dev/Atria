# Changelog

## Atria 0.13

- Added a unified user guide covering Atria's current features.
- Added the bilingual `/wiki/` web section for the release.
- Added migration information for users upgrading from Atria 0.12.

## Coming soon

### A board for each alter

Each alter will be able to have a separate wall-like space for updates, notes,
or moments. Authorized friends will be able to see, comment on, and react to
posts. Visibility and access will be configurable for each alter.

The feature will preserve privacy as a priority: nothing will be shared
without permission.
