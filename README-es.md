# Atria

## Un espacio para tu sistema

Atria es una aplicación privada para sistemas plurales. Reúne herramientas
para organizar el día a día, conocer mejor a cada identidad y cuidar vuestro
bienestar.

## ¿Qué puedes hacer con Atria?

- Crear perfiles con nombres, pronombres, colores, imágenes y detalles propios.
- Registrar quién está al frente y quién comparte el fronting.
- Escribir un diario y guardar notas privadas.
- Anotar cómo os sentís y observar vuestra evolución con el tiempo.
- Organizar citas, rutinas, recordatorios, proyectos y tareas.
- Guardar deseos, decisiones, normas y relaciones internas.
- Llevar un registro de libros, películas, juegos y otros intereses.
- Gestionar gastos, presupuestos, ahorros y pagos periódicos.
- Usar espacios privados para la comunicación interna y el Headspace.
- Conectar dispositivos, hacer amistades y chatear si activáis las funciones online.

## Tu privacidad es lo primero

Puedes usar Atria sin crear una cuenta. La información se guarda en tu
dispositivo y las funciones online son opcionales.

Si decides activarlas, podrás elegir qué información compartir. Los datos
privados se protegen antes de salir del dispositivo y las copias online están
cifradas.
